C. Pair Sums
time limit per test
2 seconds
memory limit per test
256 megabytes
input
standard input
output
standard output

You are given an array $$$a$$$ of $$$n$$$ integers and a number k. Count the pairs $$$(i, j)$$$ with $$$i < j$$$ and $$$a_i + a_j = k$$$.

See the editorial & the picture:

Long dashes — and non-breaking spaces stay.

Input

The first line contains n and $$$k$$$ ($$$1 \le n \le 2 \cdot 10^5$$$).

  • first
  • second
Output

Print one integer.

Examples
Input
3 4
1 2 3
Output
1
Input
5 10
5 5 5 5 5
Output
10<&>
Note

In the first test the only pair is $$$(1, 3)$$$.
